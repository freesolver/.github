## About

FreeSolver provides developer-focused APIs, SDKs, and tools for CAPTCHA automation, testing, and integration.

Our goal is to keep the developer experience simple:

* Clean API design
* Lightweight SDKs
* Straightforward documentation
* Predictable pricing
* Fast integration
