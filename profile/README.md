## API

FreeSolver uses a simple task-based API.

```text
POST /api/v1/createTask
GET  /api/v1/jobs/:id
```

Applications can create a task, retrieve its status, and process the result through the same consistent API structure.

[Read the documentation](https://freesolver.me/docs)
